# 原生执行首次错误记录

原生执行异常首次发生时，在加密的 `native_jobs.payload.first_error` 中保存时间、阶段和固定错误代码，并在操作日志中记录一次 `native_execution_first_error`。X 查询额外记录操作名、HTTP 状态、错误类别和最多 20 个有限范围的整数错误码。

不保存上游错误原文、请求头、Cookie、代理凭据、请求变量、银行卡资料或付款链接。后续查询不会覆盖首次错误；日志写入受原订单状态、工作令牌和租约共同约束，已关闭订单不能由迟到响应恢复。

记录不增加任何重试。`creating` 或 `tokenizing` 的结果未知时仍只保留原单核对，不能重新提交创建、换卡扣款或自动确认付款。

独立创建账单诊断必须另行得到用户授权：仅针对指定账号和套餐发起一次创建请求；不得恢复关闭订单、冻结点数、提交银行卡或调用 Stripe 确认付款。原始诊断响应如需保留，应加密后存入受限文件，不放入应用日志或 Git。
